# خدمة بيت | توثيق المشروع التقني

## نبذة عامة
موقع هبوط (Landing Page) عالي الأداء وموجه لزيادة معدل التحويل (CRO) لبراند **خدمة بيت | خدمات منزلية متكاملة** في المنطقة الشرقية بالمملكة العربية السعودية (الدمام، الخبر، القطيف، الظهران، سيهات، الجبيل، والأحساء).

---

## أهداف التحويل (Conversion Objectives)
1. **التحويل الأساسي (Primary Conversion)**: محادثة واتساب فورية مع رسائل محددة السياق مسبقاً (حسب الخدمة أو المدينة).
2. **التحويل الثانوي (Secondary Conversion)**: اتصال هاتفي مباشر عبر أزرار الاتصال وشريط التثبيت السفلي للهواتف.

---

## بنية المشروع والملفات
```
/
├── index.html                  # مدخل HTML مع الخطوط (Tajawal)، RTL، ووسوم SEO
├── metadata.json               # بيانات التطبيق والاسم الوصفي
├── src/
│   ├── main.tsx                # نقطة الانطلاق لتطبيق React
│   ├── App.tsx                 # التركيب الرئيسي لجميع أقسام صفحة الهبوط
│   ├── index.css               # متغيرات الـ Design Tokens وقواعد الوصولية (A11y)
│   ├── types/
│   │   └── index.ts            # الواجهات البرمجية ونماذج البيانات (TypeScript)
│   ├── config/
│   │   └── business.ts         # المصدر الوحيد للبيانات وإعدادات البراند والخدمات
│   ├── utils/
│   │   ├── whatsapp.ts         # منشئ روابط ورسائل الواتساب الديناميكية
│   │   └── analytics.ts        # وحدة التتبع الآمن للأحداث (GA4 / GTM)
│   └── components/
│       ├── BrandLogo.tsx       # شعار وهوية البراند
│       ├── WhatsAppIcon.tsx    # أيقونة الواتساب الرسمية
│       ├── ServiceIcon.tsx     # محول الأيقونات لخدمات المنزل
│       ├── StructuredData.tsx  # بيانات Schema.org بتنسيق JSON-LD
│       ├── Header.tsx          # الترويسة الرئيسية وقائمة الجوال
│       ├── Hero.tsx            # القسم الافتتاحي ونداء التحويل الأساسي
│       ├── TrustStrip.tsx      # شريط الثقة الحقيقي بدون أرقام وهمية
│       ├── ServicesSection.tsx # بطاقات الخدمات الـ 8
│       ├── QuickServicePicker.tsx # محدد الخدمات السريع بنقرة واحدة
│       ├── WhyKhidmaBeit.tsx   # مزايا الخدمة العملية
│       ├── HowItWorks.tsx      # خطوات طلب الخدمة الثلاث
│       ├── ServiceAreas.tsx    # شبكة مدن المنطقة الشرقية الـ 7
│       ├── BeforeAfterSection.tsx # قسم قبل/بعد (مشروط بالصور الحقيقية فقط)
│       ├── ProofSection.tsx    # قسم التراخيص والإثباتات (مشروط)
│       ├── ReviewsSection.tsx  # دعوة مشاركة تجربة العميل (بدون تقييمات مزيفة)
│       ├── FAQSection.tsx      # الأسئلة الشائعة بنظام الأكورديون
│       ├── FinalCTA.tsx        # نداء التحويل الختامي عالي التباين
│       ├── Footer.tsx          # التذييل ومعلومات التواصل
│       └── MobileStickyBar.tsx # شريط التحويل الثابت أسفل شاشة الجوال
└── docs/
    ├── README.md               # دليل التشغيل والبنية
    ├── DESIGN.md               # نظام الألوان، الخطوط، والـ UI
    ├── SEO.md                  # استراتيجية ومخطط الـ SEO
    └── CONTENT.md              # دليل تعديل المحتوى وبيانات العميل
```

## التشغيل والتطوير
- **تشغيل بيئة التطوير**:
  ```bash
  npm run dev
  ```
- **الفحص البرمجي والأنماط (Lint)**:
  ```bash
  npm run lint
  ```
- **بناء النسخة الإنتاجية (Build)**:
  ```bash
  npm run build
  ```
