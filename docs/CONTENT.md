# إدارة المحتوى وتحديث بيانات العميل | خدمة بيت

## المصدر الموحد للبيانات (Single Source of Truth)
تتم إدارة كافة بيانات البراند، أرقام التواصل، والخدمات عبر الملف:
`/src/config/business.ts`

---

## كيفية تعديل أرقام الواتساب والاتصال
في ملف `/src/config/business.ts`:
```typescript
export const BUSINESS_CONFIG: BusinessConfig = {
  name: 'خدمة بيت',
  descriptor: 'خدمات منزلية متكاملة',
  phone: '966501234567', // أدخل رقم الاتصال الحقيقي هنا
  formattedPhoneDisplay: '050 123 4567', // الصيغة المرئية
  whatsappNumber: '966501234567', // رقم الواتساب الرسمي
  region: 'المنطقة الشرقية بالمملكة العربية السعودية',
  // ...
};
```
بمجرد تعديل هذا الملف، سيتم تحديث جميع الأزرار والروابط وشريط الجوال والتذييل تلقائياً في كل أنحاء الموقع.

---

## إضافة صور قبل / بعد (Before & After) الحقيقية
إذا قام العميل بتزويدك بصور حقيقية لأعمال الشركة، أضفها في مصفوفة `BEFORE_AFTER_DATA`:
```typescript
export const BEFORE_AFTER_DATA: BeforeAfterItem[] = [
  {
    id: 'ba-1',
    serviceName: 'تنظيف كنب ومجالس',
    beforeImgUrl: '/images/before-sofa.jpg',
    afterImgUrl: '/images/after-sofa.jpg',
    verified: true, // يجب أن تكون true ليظهر في الموقع
  },
];
```
إذا كانت المصفوفة فارغة، سيظل القسم مخفياً بأمان دون عرض صور وهمية.

---

## إضافة آراء العملاء الحقيقية (Customer Reviews)
عند استلام تقييمات موثقة من العملاء:
```typescript
export const REVIEWS_DATA: ReviewItem[] = [
  {
    id: 'rev-1',
    authorName: 'أبو فهد',
    cityName: 'الدمام',
    serviceUsed: 'تنظيف مكيفات',
    comment: 'دقة في الموعد وشغل مرتب.',
    verified: true,
  },
];
```

## كيفية عمل رسائل الواتساب الديناميكية
تقوم الدالة `buildWhatsAppUrl()` بتوليد رسائل مخصصة حسب السياق:
- **الزر العام**: "السلام عليكم، أحتاج الاستفسار عن خدمات خدمة بيت."
- **زر بطاقة الخدمة**: "السلام عليكم، أحتاج خدمة تنظيف المكيفات."
- **زر بطاقة المدينة**: "السلام عليكم، أحتاج خدمة منزلية في الخبر."
- **زر محدد الخدمات السريع**: "السلام عليكم، أحتاج تنظيف كنب."
